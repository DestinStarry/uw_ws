# 实物迁移与标定

本次目标是相同的可观测条件和控制代码，不代表已辨识出真实水动力。

## 控制参数只有一份

robot.yaml 同时用于 robot.launch.py 和 simulation.launch.py：PID、死区、松杆策略、
名义推力几何、静力矩前馈完全共用。仿真不再从对象 XML 在线生成控制参数。
名义几何在本次迁移时由 CAD/XML 快照初始化，不会随对象模型修改自动追踪。
当前唯一保留的控制覆盖是 moment_sign：原实物接口 -1，模型坐标 +1。
这是现有安装/坐标约定差异，不能未经单轴验证就统一改号。

共享参数此次采用近期仿真配置：0.5°死区、稳姿优先松杆、静力矩系数约 1.828 Nm。
这些也将影响后续实物 ROS2 启动，尚未通过水下标定；原配置在本次备份中保存。
软件默认串口 dry_run=true，未连接或运行真实推进器。

## 无舵角反馈

控制器和分配器仅使用手柄、IMU、压力深度及指令限速推算舵角。
仿真舵机关节实际位置、实际推力、位置和线速度均不进入控制闭环。
估算舵速和 plant.yaml 的执行器模型各自独立；无传感器时二者本来就可能存在误差。
simulation/pose 默认关闭；publish_truth:=true 只供离线诊断，控制节点没有订阅它。

## 已从 low_control2 确认的协议

CTRL 四位小数；内部推力顺序 1/3/2/4，经串口重排为物理 1/2/3/4。
PWM 50 Hz；Motor.cpp 使用 1500+截断(thrust*400)，方向修正表四路为 1。
Servo.cpp 使用 1500+截断(angle_deg*500/90)，逻辑 ±90°。
模型中的电调方向修正与已校正接线相抵消，不额外反转物理正推力。

## 估计值集中在 plant.yaml

30ms 指令延迟、120ms 转子时间常数、
电调死区和非线性推力曲线尚无实测数据，默认分别为 0 和线性（指数 1）；
180°/s 舵速、50ms 舵机时间常数、0.3°间隙：均为工程估计，未实测。
IMU 100Hz/2s 校准对应原 SDK 设置；20ms 延迟、0.15°噪声、陀螺偏差为估计。
深度 2Hz、50ms 延迟、5mm 噪声为估计；变化率由压力样本差分滤波，不读取真实竖直速度。
浮心高于重心2cm、排水体积自动中性、水阻和模型质量分布也需要验证。
对象模型的二次曲线会暴露当前线性推力换算误差，不能把命令 N 当作已测得推力。

## 推荐的标定顺序

1. 确认实物 IMU 轴、推进器通道、舵机零位和旋转方向。
2. 用录像/计时测舵机空载与水下响应，不要求新增角度传感器。
3. 测不同 PWM 的正反转静推力，更新推力曲线和死区，再评估 N 到 PWM 的换算。
4. 测无推力滑行与转动衰减、倾斜自然回正，校准阻力、浮心和净浮力。
5. 再调共享控制参数，随后在受控条件下逐轴、低输出验证。

迁移到香橙派的是 ROS2 workspace；没有修改旧 orange Python 和 STM32 固件。
相机仍使用真实 OpenCV 采集，当前 MuJoCo 不生成双目图像、真实 RPM、电压或温度。
全浸没水动力为集中参数近似，未建模波浪、出水、尾流、空化及完整 CFD。

推力映射修订：默认 motor_deadzone=0、motor_curve_exponent=1，匹配当前线性 N/PWM 假设。
先前默认 5% 死区加平方曲线会重复压低已分配的小推力，已撤销。
非线性/死区模型仍可用于经标定的数据或单独压力测试，不能把猜测值当硬件默认。
PWM 量化、延迟、转子惯性、舵机限速和无真值反馈保持生效。

## 保持倾角的抖动修复

在相同的无舵角反馈、PWM量化、执行器延迟和有噪声 IMU 条件下处理两类问题：

* 角度规划收益小于 plan_min_improvement=0.01 时保留名义角度，推力分配仍以50Hz运行。
* 近零推力组保持现有角度，但仅在加权六维跟踪误差没有明显恶化时生效，运动需求仍可接管。
* 闭环横滚不再额外乘 sin(舵角) 缩小目标力矩，实际力臂由分配矩阵处理；开环门控保留。
* 横滚外环 Kp=3、角速度 Kp=0.5、Ki=0.02，采用连续死区和 alpha=0.5 角速度滤波。
* 俯仰/偏航保留原硬死区和 alpha=0.25 滤波，避免统一降低增益使俯仰收敛变慢。

共享配置影响 simulation.launch.py 和后续 robot.launch.py，属于仿真验证参数，仍需实物标定。
没有关闭观测噪声，也没有使用真实舵角/位置进行控制。
最终记录 validation/hold_axes_final.json：每轴保持16秒，统计最后4秒。
原始复现记录 hold_before.json 仅保持8秒，统计最后4秒，两者不是同一收敛时长。
