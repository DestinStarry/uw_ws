# 基于low2的新low3上机验收

本次没有自动烧录或驱动推进器。先保留当前可用low2固件，新low3按下面顺序验收。

1. 烧录Debug/Release，确认启动推进器/舵机中位；约5秒后收到`RDBG INIT:READY ... CFG:F MASK:1F`。CRC数据未到前CH为--，不要当作故障锁定。
2. 单独串口检查电池VOLT与万用表、四路CH，转动时有RPM，停止后为真实零。确认实际电机极对数及各通道线序。
3. 用CuteCom单独测试时，先停ROS串口节点，先发OFF。`1 1600`与`5 1600`分别为第一电机与第一舵机，数字命令输出会保持，短时测试后发OFF。原始数字PWM不做方向反相；CTRL维持原反相。
4. 控制链路先用无动力或合适隔离方式检查。Orin运行原直接CTRL/OFF版本，锁定时应持续OFF；解锁后持续CTRL，没有SYNC、WAIT_MCU或RPM放行要求。
5. 核对电机1～4的方向、两路转向舵机及夹爪。回中、锁定和急停后确认OFF及实际中位输出。
6. 用连续CTRL测试失联，停止发送后应超过200ms阈值中位；实际PWM/电调响应和IWDG复位时延需要实测。不要用一次数字PWM检查CTRL看门狗，它保留的是low2手动保持行为。
7. 正常OFF后下一条完整CTRL应立即处理。通信恢复时如果Orin仍解锁，合法CTRL可以继续输出；这是直接执行协议，不是锁存停机。
8. 按推进器使用条件进行低输出实物测试，记录完整会话日志。SPI/RPM失败不阻止控制，当前无效转速显示--。

若SPI自检失败、UART初始化FAILED或PWM行为与low2不一致，保存RDBG及原始收发日志；可回退未修改的low2，不要同时调整Orin、UI和STM32多处参数。
