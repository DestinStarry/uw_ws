# 协议与执行行为

> 摄像头更新：第七路现为±90°摄像头目标，初始0°；OFF/超时保持角度，夹爪语义已废止。见[摄像头控制](摄像头舵机控制.md)。旧对比描述的是本次摄像头更新前的基准。

下行UART6为115200/8N1，每条以LF或CRLF结束：

```text
CTRL:f1,f2,f3,f4,s1,s2,gripper
OFF
BUZZ
1 1600
5 1600
```

CTRL为7个[-1,1]有限十进制数，无额外字段/空格/NaN/Inf。电机1～4保持low2反相及1500±400μs；s1/s2为归一化±90°，PWM约1500±500μs，按low2截断取整；夹爪1500+1000×值，Orin使用±0.5。电机限幅1100～1900，舵机原始PWM限幅500～2500。单行最多127字符，从首字节接收起最多100ms；旧帧不刷新控制时间。

合法CTRL直接执行，不要求回中握手。OFF优先停止同批所有CTRL/数字命令。连续超过200ms无有效CTRL则停机，后续完整合法CTRL可恢复。保留SysTick独立超时和IWDG，没有SYNC、MCU心跳或反馈就绪门控。BUZZ和数字PWM不刷新CTRL超时。

数字命令ID1～4为原始电机PWM（不反相），5～7为原始舵机PWM，8为蜂鸣。独立数字命令不启动CTRL看门狗，输出保持到新命令/OFF；如果此前CTRL仍激活，既有CTRL超时仍有效。手动测试先停止Orin串口节点、发OFF，结束再发OFF。BoardConfig的kLegacyPwmEnabled可关闭数字控制。

正常完整OFF后，在已知行边界可立即接收下一条完整指令。若当前为半帧或UART故障，则丢弃到分隔符后恢复，防止把残片当命令。UART IRQ只缓存字节和接收时间，解析在主循环进行；RxCplt遇HAL错误不提前重挂，主循环完成错误恢复。

上行10Hz：

```text
VOLT:23.80 CH0:0 CH1:2314 CH2:-- CH3:--
```

V为电池电压，CH0～3为RPM。无效/过期为--，真实零为0。默认每5秒附加一次RDBG摘要，初始化/SPI/RX/BAD只观察，不刷新测量有效期，不参与控制门控。kRpmSummaryEnabled可关闭摘要；旧详细DIAG由kDiagnosticsEnabled控制，默认关闭。当前Orin/电脑UI的VOLT/CH字段解析可继续使用。

CH9434使用low2成功的/128、DWT 10μs完整CS时序、SCR先检和三次启动初始化读回；CRC保留滑动恢复、连续两帧确认和500ms超时。未收到真实电调数据不能用默认零值冒充有效反馈。七极对数换算仍需核对电机型号。
