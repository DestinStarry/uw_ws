# 通信协议与安全行为

## 下行：Orin → UART6

```text
CTRL:f1,f2,f3,f4,s1,s2,gripper
OFF
BUZZ
```

每条以 LF 或 CRLF 结束；空行忽略。CTRL 必须恰好包含 7 个有限十进制数，全部在 [-1,1]，允许十进制指数，不允许空格/十六进制/NaN/Inf/额外字段。单行最多 127 个字符（不含终止符），从首字节到处理不能超过 100ms。帧的接收时间按首字节记录，不会把堵塞队列中的旧命令当作新命令续期。

- f1~f4：物理电机 1~4，仍各自反相，PWM=1500±400µs。
- s1/s2：逻辑 ±90°，PWM=1500±500µs。四舍五入修正旧浮点截断在端点少 1µs 的问题。
- gripper：保留原归一化映射 PWM=1500+1000×value；当前 Orin 发 ±0.5，即 1000/2000µs。
- OFF：四电机及三舵机均回中，后续需重新收到零推力帧。不是仅停电机、保持舵机位置。
- BUZZ：非阻塞鸣响，不刷新控制看门狗。
- 旧数字开头的原始 PWM 指令不再接受；未知命令按异常停机。

## 恢复条件

上电、OFF、200ms 超时、UART 错误、超长/非法字节/队列溢出、无效或过期命令后，进入等待零推力状态。先收到一帧 f1~f4 均为 0（数值容差 0.0001）的有效 CTRL，才允许后续非零推力。s1、s2、夹爪不参与这项判断，因此零推力帧仍可能移动舵机/夹爪。

遇故障会清空接收队列并丢弃到下一个换行；连续上报的第一帧可能被用于恢复分帧，Orin 50Hz 连续发送时后续零推力帧可恢复。操作时保持摇杆回中再解锁。若 Orin 已显示解锁但 MCU 一直不出力，先查看 NEUTRAL_REQUIRED，而不要反复加大摇杆。

同一批已排队帧中，只要存在完整 OFF，整批 CTRL 都不执行。停止期间旧输出缓存也归零，后续周期不会把旧 PWM 覆写回来。

## 上行：STM32 → Orin

常规遥测独立 10Hz，每行仅包含电压和四路转速：

```text
VOLT:15.25 CH0:1200 CH1:0 CH2:-- CH3:--
```

诊断独立 1Hz，以 DIAG 开头；包含 MCU_SEQ、MCU_MS、CTRL_ACTIVE、NEUTRAL_REQUIRED、CH_READY、STOP_REASON、RX_REJECT、SPI_ERRORS，以及 VOLT/CH0~CH3 的 VALID/AGE_MS。常规行不再重复这些字段。无效数值用 --，真实零转速用 0。

| 字段 | 含义 |
|---|---|
| VOLT | 电池电压 V；ADC 失败或数据过期时为 -- |
| CH0~CH3 | 电调物理通道 0~3 的机械 RPM；未建立 CRC 同步或过期为 -- |
| *_VALID | 1 有效、0 无效；不是默认值有效的声明 |
| *_AGE_MS | 距 MCU 成功取得样本的时间，无历史样本为 -1 |
| MCU_SEQ / MCU_MS | 遥测递增序号 / MCU HAL tick，均按 uint32 回绕 |
| CTRL_ACTIVE | MCU 当前接受了有效控制且未触发故障；不是电脑端 ARM 状态 |
| NEUTRAL_REQUIRED | 是否需要零推力恢复帧 |
| CH_READY | SPI 自检通过且当前无 SPI 访问错误，不表示四个电调都在线 |
| STOP_REASON | 最近一次停止原因：1 上电、2 OFF、4 超时、8 接收错误、16 非法/过期命令、32 严重异常；可能按位组合 |
| RX_REJECT / SPI_ERRORS | 被拒控制行 / SPI 错误诊断计数；不是通信序号确认 |

正常帧仅以 CRLF 结束，不再额外发送帧前空行。只有 TX 超时中止后的下一次发送带一次前导 CRLF，避免残余文本与新帧粘成一行。TX 静态缓冲 512B，格式化溢出则整帧不发。HAL 启动失败不占用 busy，超过 100ms 仍未结束时只中止 TX 再恢复，不取消 RX。

电压每 100ms 采样，成功后有效期 500ms；电调转速按每通道最近有效 CRC 帧计时，500ms 过期。真实零转速输出 0 且 VALID=1。SPI 访问失败、CRC 错帧和明显积压会让相应反馈失效。CRC 解码锁定要求连续两帧；全零/全 FF 字节流不视作电调帧。

当前 Orin 桥会提取这些行中的 VOLT 与 CH0~CH3 并上传电脑，-- 会使对应值失效；其它 MCU 诊断可先通过 `ros2 topic echo /hardware/rx` 查看。电脑端是否清除无效值仍依赖 UI 的 --/超时处理，不能只看界面默认 0 判断电机真实静止。
