# 精简遥测（2026-11-23）

常规数据保持 10Hz，仅发送：

```text
VOLT:15.23 CH0:1200 CH1:0 CH2:-- CH3:--
```

电压单位 V、转速单位 RPM。-- 表示无效，0 表示有效零值；四路顺序不变。常规行取消冗余 VALID 和 AGE_MS，异常值仍通过 -- 立即传递，因此当前 Orin VOLT/CH0~CH3 解析代码无需修改。

诊断另以 1Hz 发送 DIAG 行，保留运行时间、序号、控制状态、停机原因、SPI 错误和各路有效性/样本年龄。诊断行不含 VOLT: 或 CHn: 数值，不能被 Orin 当作新采样刷新。当前 /hardware/rx 会显示它，TCP 桥仍只提取常规数值。

正常发送不再有额外 data: "\r" 空行。仅发送超时中止后，下一帧前补一次 CRLF 恢复接收分帧，因此通信异常恢复时仍可能出现一次空行。

本次只改变遥测内容和频率，不改变控制、PWM、看门狗和转速采集时序；没有修复实物上观察到的 CH_READY:0 / SPI_ERRORS 增长和接收故障。相关诊断保留在 1Hz DIAG 行，需继续排查。

重新烧录新 Debug 或 Release 固件生效，Orin 不需重新编译。VS Code F5 使用 build/Debug/low_control3.elf，已配置构建前置任务；CubeProgrammer 可使用 build/Release/low_control3.hex。

查看原始数据：

```bash
ros2 topic echo /hardware/rx --full-length
```

过滤只看常规行（Linux 有 grep 时）：

```bash
ros2 topic echo /hardware/rx --field data --full-length | grep '^VOLT:'
```

验证覆盖：常规字段/真实零值/无效值、诊断 1Hz 调度、诊断不刷新采样、失败重试、TX 超时后仅一次换行恢复。
