# 当前精简遥测

常规数据10Hz：

```text
VOLT:23.80 CH0:0 CH1:2314 CH2:-- CH3:--
```

每5秒额外附加一次精简摘要（同一非阻塞发送缓冲，完整两行，不与其他帧交错）：

```text
RDBG INIT:READY TRY:1 ERR:0 CFG:F MASK:1F SPI_ERR:0 FIFO_ERR:0 RX:100,100,100,100 BAD:0,0,0,0
```

INIT/TRY/ERR/CFG为启动配置结果/次数/原因/四路通过位图；ERR=0通过、1 SPI、2时钟读回、3UART配置。MASK=1F表示最近SCR五组数值匹配，结合SPI_ERR累计HAL错误判断。FIFO_ERR为异常长度次数。RX/BAD顺序CH0～3；BAD为滑动CRC拒绝窗口数，不是固定10字节坏帧数。

摘要格式化不访问SPI，不刷新电压/RPM样本时间。默认不发寄存器、原始HEX或旧详细DIAG。BoardConfig中的kRpmSummaryEnabled可关闭5秒摘要；kDiagnosticsEnabled=true可开启旧DIAG，供需要年龄/控制状态的调试。

无效测量为--，真实有效零为0。正常行无多余空行；仅TX超时中止后，下一次补一次CRLF恢复对端分帧。TX失败不取消RX，主循环可继续收CTRL。

```bash
ros2 topic echo /hardware/rx --full-length
```

当前Orin无需为这些字段重新编译。电调额外电压/电流字段未在此版本上传，保留原电池ADC电压来源；Orin CPU温度仍由Orin节点提供。
