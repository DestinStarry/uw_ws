# MuJoCo 被控对象

当前迁移说明见工作空间 docs/实物迁移与标定.md。

| 模块 | 职责 |
| --- | --- |
| sim_engine.py | 刚体动力学、重力、浮力、浮心扶正、水阻及物理步进 |
| actuator_model.py | CTRL/PWM 量化、50Hz保持、延迟、非线性推力及转子/舵机响应 |
| sensor_model.py | 100Hz名义IMU、2Hz估计压力采样、延迟、校准、噪声；深度率由样本差分 |
| mujoco_node.py | ROS2 指令入口、超时、观测发布、可选调试真值与窗口 |
| model_geometry.py | 离线名义几何提取/校验；仿真启动不再用它在线配置控制器 |

robot.yaml 是两种后端共用的名义控制/分配参数；plant.yaml 仅描述模拟被控对象。
模型实际舵角/位置/实际推力不进入控制器，控制器按自身名义舵速推算机械角度。
立即回中是目标指令，不会将推算角度或物理关节瞬移到零。
simulation/pose 默认不发布；publish_truth:=true 仅供测试和离线诊断。
无 IMU 初始校准数据时不发布有效 IMU，模拟实物上电校准过程。

默认中性浮力、浮心高2cm。按 B 后命令停止，推进器按模型惯性衰减，机体被动回水平。
闭环松杆仍维持目标姿态，可能继续输出纠正推力。相机仍需真实 OpenCV 节点。
无水面穿越、波浪、CFD、真实RPM/电压/温度模拟。水动力和执行器动态均需实物标定。

推力映射修订：默认 motor_deadzone=0、motor_curve_exponent=1，匹配当前线性 N/PWM 假设。
先前默认 5% 死区加平方曲线会重复压低已分配的小推力，已撤销。
非线性/死区模型仍可用于经标定的数据或单独压力测试，不能把猜测值当硬件默认。
PWM 量化、延迟、转子惯性、舵机限速和无真值反馈保持生效。

线性映射恢复后，以60%输入持续3秒，六个方向实际位移均通过验证；报告见 validation/thrust_motion.json。


传感器安装与双目预览：见 `../../docs/仿真IMU与双目相机.md`。
